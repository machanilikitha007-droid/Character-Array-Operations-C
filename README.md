# Character Array Operations in C

**Author:** M.Likitha

## Description

This program demonstrates how to store a word in a character array,
find its length, and access each character individually.

## File

character_array_operations.c

## Concepts Used

- Character arrays
- `strlen()`
- Array indexing
- `for` loop
- String input

## How to Run

gcc character_array_operations.c -o character_array_operations
./character_array_operations

## Sample Output

Enter a word: Hello
Character array: Hello
Length: 5
Characters:
H
e
l
l
o
